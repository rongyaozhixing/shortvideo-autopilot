# 抖音作品复盘分析（shipin 项目）

每条视频发布**约 24 小时后**执行的复盘流程：拉数据 → 看评论区 → 归因分析 → 输出优化建议。与 `/shipin-pipeline` 配对：发布登记 → 隔天复盘 → 反馈到下一期制作。

## 触发
- 用户说："复盘 / 看看那条视频 / 分析一下数据 / 评论区咋样" 或新会话里 review_queue 中有待复盘项
- 发布当天先登记：在 `review_queue.md` 追加一条（日期/标题/作品链接/发布账号），并更新 [[shipin-工作流-pipeline]] 记忆

## Step 1: 拉作品数据（抖音创作者中心）

nuphus 浏览器打开 `https://creator.douyin.com/creator-micro/content/manage`（需已登录）：
- 找目标作品（按标题/日期），看"审核中→已发布"状态
- 用 `browser_evaluate` 读页面文本，抓取：播放量、点赞、评论、分享、收藏
- 数据概览页（数据中心）：`https://creator.douyin.com/creator-micro/data` 看完播率、平均播放时长、粉丝画像（如果该账号有）

核心指标及含义：
| 指标 | 健康线 | 含义 |
|---|---|---|
| 播放量 | 粉丝数×5 以上算跑出流量池 | 破池才有后续 |
| 完播率 | 5s 完播>70%、整体>30% | 钩子决定 |
| 点赞率 | >3%（赞/播） | 内容价值 |
| 评论率 | >0.5% | 互动设计 |
| 分享率 | >0.3% | 传播性 |
| 涨粉 | 播放/50 以上 | 关注转化 |

## Step 2: 看评论区

- 作品管理页点进作品，或用 `https://www.douyin.com/` 搜索作品标题看公开评论区
- 逐条读评论（`browser_evaluate` 提取），分类：
  - 😍 共鸣型（"我儿子也…"）→ 这类是核心受众信号
  - 🤔 质疑型（"假的吧""瞎编"）→ 检查事实/标注来源
  - 😡 对立型（C罗粉/黑互撕）→ 天然流量但注意引导
  - ❓ 提问型（"后来呢""迷你罗现在咋样"）→ **下一期的选题素材！**
- 点赞最高的前 3-5 条评论重点分析：它们在争论什么、情绪是什么

## Step 3: 归因分析（为什么火/为什么不火）

对照数据健康线，判断卡在哪一环：
- 播放低 → 大概率标题/封面/前3秒钩子没抓住（竖封面不吸引 / 标题没冲突感）
- 播放可以但完播低 → 开头铺垫太长，钩子后 5 秒没进正题
- 完播高但点赞低 → 内容有看头但没"价值点"（没金句/没共鸣点/没反转）
- 评论少 → 没有互动钩子（结尾没提问 / 话题太泛）
- 分享少 → 缺"我要转给某人"的属性（教育孩子类适合转给家长群）
- 涨粉差 → 账号定位不清，用户看了不觉得"关注你还能看到更好的"

## Step 4: 输出复盘报告

写 `output/<视频名>/review_<日期>.md`，结构：
```
## 数据（发布 N 小时）
播放 X / 点赞 Y / 评论 Z / 分享 W / 涨粉 V
## 评论区热点
- 高赞评论 1（情绪/观点）
- 高赞评论 2
## 归因
- 做对了：...
- 卡点：...
## 下一期优化
1. 标题方向：...
2. 钩子调整：...
3. 评论区催生的选题：...
4. 发布时间/话题调整：...
```

## Step 5: 反馈到流水线

- 把"评论区催生的选题"加进选题池（建议存 `scripts/topics_pool.md`）
- **把复盘结论写进经验库 `scripts/lessons.md`**（✅做对了 / 🔧改进 / 🧪下一条要试），供 `/shipin-pipeline` Step 0 下次创作前必读
- 下一期做视频时按复盘结论调整对应环节（标题模板/钩子写法/话题组合）
- 更新 review_queue.md：标记该条已复盘

## 爆款通用公式（复盘时对照）

- **标题**：数字 + 冲突 + 名人/热词 + 悬念（如"C罗16岁儿子偷走百万美金讨好女友，被老爸当场抓包！"）
- **封面**：大字标题 + 冲突画面 + 高对比色（黄/红）
- **前3秒钩子**：直接抛最大悬念/最劲爆信息，别铺垫
- **全程节奏**：每 10-15 秒一个信息点/反转
- **结尾互动**：站队式提问（"你管还是惯？评论区站队"）
- **话题**：名人话题 + 泛流量话题（#吃瓜#八卦）+ 内容垂直话题 三组组合
- **发布时间**：晚 19-21 点（流量高峰）
