# shipin 短视频 Rubric（v1）

> 打分标准：每个维度 0-5 分，总分 0-25。**发布前打分，写进预测文件，不可改**。
> 依据：cheat-on-content 方法论 + shipin 实测经验。复盘后可按数据校准权重（见 lessons.md）。

## 五个维度

### 1. 选题热度（权重 1.0）
- 5：全球级名人/现象级热点，正在发酵中（如 C罗、OpenAI 大新闻）
- 4：热门名人 + 强冲突/悬念
- 3：大众话题但无爆点，或热点已过峰
- 2：小众/冷门，仅垂直受众感兴趣
- 1：无热度，纯个人琐事
- 0：完全无传播性

### 2. 钩子强度（前 3 秒）（权重 1.2）
- 5：第一句直接抛最大悬念/劲爆信息，数字+冲突（"C罗卡里少了一百万美金"）
- 4：开场有悬念，但铺垫了半句
- 3：正常开场，无强钩子
- 2：开头寒暄/自我介绍/废话
- 1：开头在讲背景，30 秒还没进正题
- 0：不知道在讲什么

### 3. 结构节奏（信息密度）（权重 1.0）
- 5：每 10-15 秒一个信息点/反转，全程无尿点
- 4：节奏紧凑，个别段落稍平
- 3：结构完整但中段拖沓
- 2：铺垫过长或结尾仓促
- 1：流水账
- 0：逻辑混乱

### 4. 互动钩子（结尾）（权重 1.2）
- 5：站队式提问/投票（"你管还是惯？评论区站队"）
- 4：开放提问，引导讨论
- 3：有引导但太泛（"你怎么看"）
- 2：结尾无互动设计，或只喊关注
- 1：结尾突兀
- 0：无结尾

### 5. 话题标签组合（权重 0.6）
- 5：名人 + 泛流量 + 垂直 三组完整
- 4：两组，含热门标签
- 3：只有泛流量或只有垂直
- 2：标签与内容无关
- 1：无标签
- 0：标签堆砌/违规词

## 总分与预测锚点（参考）

| 总分 | 预期表现 |
|---|---|
| 20-25 | 高潜：预期播 5 万+，可能进大流量池 |
| 15-19 | 中上：预期 1-5 万 |
| 10-14 | 中等：预期 3k-1 万 |
| 5-9 | 偏低：预期 <3k |
| 0-4 | 不建议发布 |

> 这些锚点是**初始估计**，会随复盘数据校准（参考 lessons.md 的经验条目和实际 T+3 数据）。
